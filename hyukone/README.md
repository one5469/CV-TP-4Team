# 군용 항공기 이미지 분류

교통수단 이미지 분류를 진행한 3인 팀 프로젝트에서 군용 항공기 기종 분류를 담당했습니다.

- 기간: 2024.03.26–2024.03.27
- 담당: 권혁원 / 항공기 주제 선정, 이미지 데이터 구성, CNN 학습 실험
- 데이터: 기종별로 수집·정리한 군용 항공기 이미지
- 기술: Python, PyTorch, torchvision

## 담당 작업

- 군용 항공기 이미지 수집 및 기종별 데이터 구성
- 항공기 종류·국가·기종 정보를 정리하고 이미지 전처리 조건 구성
- 96×96 이미지 입력을 사용하는 CNN 분류 모델 구현
- 학습·검증·테스트 분할과 학습 손실·정확도 확인
- 학습이 불안정한 구간을 검토하고 데이터 정리·모델 조정 방향 제안
